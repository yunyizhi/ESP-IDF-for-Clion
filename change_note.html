0.7

en:
  • Added a serial port settings dropdown list, which can list serial ports and display some USB serial port models.
  • Added custom task configuration for the task tree, allowing custom addition of idf.py commands or local commands.
  • Added Toolchain environment variable cache isolation for more comprehensive multi-Profile support: supports configuring multiple different versions of idf Toolchain to the same project for compilation without interference.
  • Added new debug types to facilitate configuring multiple different debug tasks in multi-Profile scenarios.
  • Fixed the issue where child elements of menu type with the is_menuconfig attribute set to true could not be displayed on the Menu-config UI.
  • The Menu-config UI added a button to enable displaying hidden items in search results, allowing search results to show invisible items.
中文:
  • 添加串口设置下拉列表，可列出串口并展示部分usb串口型号
  • 添加了任务树自定义任务配置，可使用自定义添加idf.py命令或者本地命令
  • 添加了Toolchain环境变量缓存隔离，对多Profile支持更加全面:支持以多个不同的版本的idf Toolchain同时配置到同一项目进行编译，互不干扰
  • 添加了新的调试类型，便于多Profile场景配置多个不同的调试任务
  • 修复了Menu-config UI上is_menuconfig属性为true,的menu类型子元素无法展示的问题
  • Menu-config UI增加了在搜索结果中使能展示隐藏项目的按钮，允许搜索结果展示不可见项

0.5

en:
  • Resolved the issue of errors when reading environment variables on macOS by adopting a unified approach of execution within a blocking modal dialog.
  • Fixed the problem preventing debugging from starting on macOS.
  • Added a popup menu in the bottom-right status bar for setting the ESP-IDF target.
  • Task execution now prioritizes standard run configuration tasks over terminal commands, enabling automatic termination of an ongoing Monitor task when a new serial port task is requested. Added a general filter to the task console view, allowing navigation to specific file lines by clicking file links in the console, with stderr output displayed in red.
  • Task trees now support specifying a Profile, allowing assignment of the corresponding Profile to run items when multiple CMake Profiles are available.
中文:
  • 解决MacOs读取环境变量报错问题，统一采取阻塞模态窗执行。
  • 解决MacOs无法启动调试的问题。
  • 增加右下角状态栏设置target的状态Popupmenu
  • 将执行任务优先采用常规运行配置任务项执行而非终端命令，实现了常规任务的Monitor任务被新请求串口任务自动关停；增加了任务控制台视图通用过滤器， 可以点击控制台视图上的文件链接进行跳转文件具体行，stderr会使用红色。
  • 任务树支持了指定Profile，在多CMake Profile可以指定运行项对应的Profile
